Privacy Policy

workbuddy — a private, single-user Google API client. Last updated: 22 September 2026.

Summary: workbuddy accesses Google user data belonging to its single owner, and to nobody else. That data stays on the owner's own computer. It is never transmitted to, stored on, or shared with any third party, and it is never used for advertising or to train machine-learning models.

1. Who this policy applies to

workbuddy is a personal automation tool operated by a single individual on his own device. It is not offered to the public and has no other users. The only Google account that can authorize workbuddy is the owner's own account.

2. Google user data that is accessed

When the owner authorizes workbuddy, it may access the following data from that one Google account, and only when performing a task the owner has initiated:

  • Google Drive — file names, metadata and file contents, so the owner's files can be listed, read, organised and exported.
  • Google Sheets — spreadsheet contents, so the owner's spreadsheets can be read and updated.
  • Google Calendar — calendars and events, so the owner's schedule can be read, and events created or updated.
  • Basic account information — the email address of the authorizing account, used only to label which account a stored token belongs to.

workbuddy does not request or access any Google data beyond what is listed above.

3. How the data is used

Solely to carry out the automation tasks the owner requests, on the owner's own machine. There is no analytics, no profiling, no behavioural advertising, and no automated decision-making about any person.

4. Storage and security

  • OAuth access and refresh tokens are stored as files on the owner's own computer, with file permissions restricted to the owner's user account.
  • Data retrieved from Google is processed in memory and written only to the owner's local storage.
  • workbuddy has no server, no cloud backend and no database. No Google user data is uploaded anywhere.

5. Sharing and disclosure

None. Google user data is not sold, rented, transferred, or disclosed to any third party. It is not used or transferred for the purposes of advertising, and it is not used or transferred to train or improve generalised artificial-intelligence or machine-learning models. Google user data is not made available to humans for review.

6. Retention and deletion

  • Retrieved Google data is kept locally only for as long as it is needed for the task, and can be deleted by the owner at any time by removing the corresponding local files.
  • OAuth tokens are kept until the owner revokes them.

7. How to revoke access

The owner can revoke workbuddy's access to the Google account at any time at myaccount.google.com/permissions. Revoking access immediately invalidates the stored tokens. The owner can also delete the local credential files to remove all remaining copies of the tokens.

8. Limited Use

workbuddy's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes to this policy

Any change to this policy will be published on this page with an updated revision date.

10. Contact

This app is operated for personal use only. Contact details for the app owner are the developer contact registered on the app's Google Cloud project and shown on its OAuth consent screen.
